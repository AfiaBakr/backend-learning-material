## 🎯 Learning Objectives

After studying these notes, learners should be able to:

- Understand the fundamentals of modern JavaScript.
- Declare variables using `let` and `const`.
- Write concise functions using arrow-function syntax.
- Extract values from arrays and objects using destructuring.
- Copy and combine arrays using the spread operator.
- Collect function arguments using the rest operator.
- Create classes and work with Promises.
- Organize JavaScript code into reusable modules.
- Use named and default exports and imports.
- Access nested properties safely using optional chaining.
- Provide fallback values using nullish coalescing.
- Solve beginner-level JavaScript practice questions.

## 🛠️ Requirements

- A modern web browser, such as Google Chrome.
- A code editor, such as Visual Studio Code.
- Basic knowledge of JavaScript.
- The Live Server extension for running browser-based module examples.

## 🚀 How to Run the Examples

1. Create a project folder.
2. Create the required JavaScript files, such as `main.js`, `math.js`, and `student.js`.
3. Write the examples in their respective files.
4. For module examples, create an `index.html` file and include the main JavaScript file:

   ```html
   <script type="module" src="./main.js"></script>
   ```

5. Open the project using Visual Studio Code.
6. Start Live Server.
7. Open the browser and check the output in the Developer Tools Console.
